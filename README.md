## Struttura delle cartelle

Ogni corso ha una directory dedicata sotto `corsi/`. Le sottocartelle
raccolgono, quando presenti:

- `materiale-prof/`: materiale fornito dal docente.
- `universita/`: appunti e attivita svolte all'universita.
- `casa/`: appunti e attivita svolte a casa.
- `esercizi/`: esercizi, prove d'esame e soluzioni.
- `notes-onenote/`: appunti organizzati per argomento.

## Convenzioni

- I nomi delle directory sono scritti in minuscolo, usando lettere ASCII,
  numeri e trattini.
- I nomi dei file di contenuto non vengono modificati senza una richiesta
  specifica.
- Le directory vuote sono conservate tramite un file `.gitkeep`.
- Il README di ogni corso contiene le informazioni su docente,
  anno/semestre, CFU, stato e struttura del corso.
